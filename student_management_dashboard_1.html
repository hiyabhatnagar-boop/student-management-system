New record

A unique whole number, 1 or higher.

Record rules

  • Roll numberMust be unique. Duplicates are rejected, not overwritten.
  • NameLetters, spaces, dots, hyphens and apostrophes only.
  • MarksAny number from 0 to 100. Decimals are fine.
  • EditingRoll number is locked once a record exists. Delete and re-enrol to change it.

Class summary

What this page is

This is a browser companion to the C++ console project. It does not run or compile the C++ code. Records live in this browser's localStorage, so they stay on this device and survive a refresh.

The record in C++

struct Student {
    int    rollNo;
    string name;
    float  marks;
};
vector<Student> students;
Here each record is a JavaScript object with the same three fields, held in an array.

DSA concepts in the console project

Structure
Groups roll number, name and marks into one record.
Collection
A vector holds every record for display and management.
Linear search
Checks records one by one to find a matching roll number.
Bubble sort
Repeatedly compares neighbours to order students by marks.
Functions
Separate add, display, search and sort into their own routines.
Menu loop
A loop with a switch statement drives the console menu.

On this page, search and sort use the browser's built-in filter and sort rather than hand-written linear search or bubble sort.
