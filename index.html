Project notes

Organised records. Clearer decisions.

This Student Management System is a web-based companion to a beginner C++ Data Structures and Algorithms project. It demonstrates common student-record operations through a simple interface. The website runs in the browser and does not execute the original C++ program.

The original C++ implementation uses a student structure, a collection of records, functions, linear search and bubble sort. This interface demonstrates equivalent user-facing tasks, with browser storage for persistence.

Structure

Groups roll number, name and marks into one student record.

Collection

Keeps multiple student records together for display and management.

Linear search

Checks records to find a matching roll number.

Bubble sort

Compares marks and arranges students from highest to lowest.

Functions

Separates tasks such as adding, displaying and searching records.

Local storage

Saves website records in this browser so they remain after refresh.
